# 🏢 Sistema de Controle de Visitantes

## 📋 Sobre o Sistema

-- Sistema moderno para controle de entrada e saída de visitantes com captura de foto via webcam e impressão de crachás.

## 🚀 Tecnologias Utilizadas

-- **Frontend**: HTML5, CSS3, JavaScript (ES6+), Bootstrap 5.1
-- **Backend**: PHP 7.4+ com PDO
-- **Banco de Dados**: MySQL
-- **Webcam**: API MediaDevices (nativa dos navegadores)

## 📦 Instalação

### 1. Requisitos do Servidor

-- PHP 8.2 ou superior (com suporte a type hints e features modernas)
-- MySQL 8.0 ou superior
-- Navegador moderno com suporte a WebRTC
