PASSO A PASSO - INSTALACAO (REDE INTERNA)

1) PRE-REQUISITOS
   - Ubuntu 24.04
   - Acesso root (sudo)
   - Codigo copiado para /var/www/sistema-visitantes-v1.0

2) GERAR CERTIFICADO (HTTPS INTERNO)
   No servidor:
   sudo SERVER_NAME=10.10.10.208 bash db/ssl_generate.sh

   Arquivos gerados (exemplo):
   - /etc/ssl/visitantes/sistema-visitantes.crt
   - /etc/ssl/visitantes/sistema-visitantes.key
   - /etc/ssl/visitantes/sistema-visitantes-ca.crt

3) DISPONIBILIZAR A CA PARA DOWNLOAD
   Copie a CA para:
   /var/www/sistema-visitantes-v1.0/public/cert/ca.crt

4) INSTALACAO DO SISTEMA
   Execute o install.sh informando a senha do banco:
   sudo DB_PASS='SUA_SENHA' bash db/install.sh

   Para habilitar HTTPS automaticamente:
   sudo DB_PASS='SUA_SENHA' ENABLE_HTTPS=1 \
     SSL_CERT_FILE=/etc/ssl/visitantes/sistema-visitantes.crt \
     SSL_KEY_FILE=/etc/ssl/visitantes/sistema-visitantes.key \
     SSL_CA_FILE=/etc/ssl/visitantes/sistema-visitantes-ca.crt \
     bash db/install.sh

5) OPCOES AVANCADAS (PRODUCAO)
   - Evitar reset do banco (padrao ja e 0):
     RESET_DB_ON_IMPORT=0
   - Nao alterar rede/firewall/ports por padrao:
     APPLY_NETWORK=0
     APPLY_FIREWALL=0
     APPLY_PORTS_CONF=0

6) ACESSO
   - HTTP:  http://10.10.10.208:8080
   - HTTPS: https://10.10.10.208

7) CERTIFICADO NAS MAQUINAS
   - Dominio: distribuir a CA via GPO
   - Fora do dominio: instalar manualmente o ca.crt

OBSERVACOES
- Para webcam funcionar sem bloqueio, HTTPS e certificado confiavel sao recomendados.
- Caso use somente HTTP, alguns navegadores podem limitar acesso a camera.
